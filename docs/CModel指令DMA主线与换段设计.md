# CModel 指令 DMA：共享 AXI、程序续装与地址契约

**2026-11-24 · LPU16/32 mixed · 给编译器、ICU、指令 DMA 合作者。** 维持一个对 DDR 的五通道 AXI Master；程序读是内部客户。已有单槽 iMEM、同代续装、排空和错误恢复保留。下一项有价值的新功能是：**编译器证明哪里能切，DMA 装载控制器在运行时自行判断何时能换，不要求 Host 每段重新发命令。** 这是提案，还不是已有硬件、正式指令或已通过的用例。

## 2. DDR 入口：区分 Host 写入镜像与 LPU 发起取指

| 环节 | DEV | 本地主线 |
|---|---|---|
| 程序从哪里来 | Loader 收到镜像描述后，以 DDR 地址取程序，不是 Host 直接灌私有 iMEM。 | runtime 可先把镜像字节写入 DDR 模型（initialize_vector）。这是**运行前布置内容**，不是指令 DMA 的 AW/W/B 事务，也不代表已建模 Host 总线。两种动作分开记账。 |
| 运行时从哪里读 | 专用 InstructionFetchDma 取指核经 wrapper 调 Ddr4Model::request_read，与数据端共享 DDR 服务模型；不是独立五通道 Master。 | Host 首次提交描述符 → 程序客户申请共享 Master → AR/R → 程序返回 FIFO → 字节重组、字 FIFO、relay → 目标 ICU 的私有 iMEM。**不占数据 SR 或 MEM 数据页。** |
| 同时有权重 LOAD、结果 STORE | 受 DDR 服务能力限制，不提供与本地一一对应的物理通道边沿。 | 程序读与数据 LOAD 共用 AR/R；数据 STORE 用同组 AW/W/B。一个沿至多一个 AR 和一个 R，但读、写通道可同时推进。逻辑取指 ID 不等于物理 AXI ID；按客户/ticket 承接返回，并保证逻辑核要求的顺序。 |

**固定不动：**只保留一套共享 Master；读请求发出前预留容量，停顿不撤销已发布事务。请求获准、AR 接受、RLAST、iMEM 末字 commit、PRIME、START 分别观测。前一个事件不能代替后一个。继续使用现有 P/RT/Q 联调值，不因增加换段描述符扩 Q。入口与实现：[本地取指适配](../include/ftlpu/icu/instruction_fetch_dma.hpp)、[共享 Master](../include/ftlpu/c2c/axi_dma.hpp)、[软件布置 DDR 镜像](https://github.com/WongWangKit/FTLPU-SOFTWARE/blob/21cccdca88de8cd4d35ac8994d3dc530638bc9d5/runtime/src/runtime/icu_program.cpp)。

## 3. 大程序：谁决定切点，谁执行换段

**现状。** DEV 的整任务 submit 不能替代本地 compute_segment / more_segments 路径。本地软件规划并驱动续装：仅在可证明安全的共同切点重用单槽，保留当前任务 generation、数据 SRAM 和活的控制状态；非末段退休不能误报 KERNEL_DONE。已有 MEM/MXM 分段用例，不保证任意有分支、活动事件或未排空 SR 波前的图都能切。**长段预热、换段、权重换页是三件事**：前者在同一 iMEM 段内边运行边取；换段要覆盖旧指令；权重页提交事件只证明数据到位，不证明旧指令槽可写。

| 候选 | 谁定切点 / 谁推进 | 取舍 |
|---|---|---|
| A　纯 DMA 自判 | 由硬件观察占用或一时空闲，自行切换 | 不推荐用于寻找切点。某拍 IQ 空或 DMA 空，不能证明未来没有旧域的定时指令、SR 返回或未决 WAIT。DMA 可自主判断**排空是否完成**，不能从空闲推断计算图语义。 |
| **B　显式安全标记＋DMA 自主续装（推荐）** | 编译器/链接器选合法切点，写段目录；硬件按退休与排空事实执行 | 合并两种想法：软件不猜物理拍，DMA 不猜依赖。首版只做共同切点和单槽，不需要第二路 AXI、双槽 iMEM 或全局冻结。 |
| C　软件逐段提交 | 软件观察完成，逐段调用现有续装入口 | 保留作当前产品行为及实验对照，容易定位错误；Host 每段参与。在 B 验收前不移除；不是新建一套兼容 ISA。 |

### B 的最小可实现版本（拟议接口，名称不占用现有 opcode）

1. **编译/链接。** 按每个目标队列实际打包后的字数切段。标记先放入**加载器可读的段目录**，不向每条 FU 指令流硬插一条指令。目录含任务内唯一 seg_id、下一段索引或 END、参与/重写队列集合、各目标 DDR 源地址与物理字数、局部退休边界和整图末尾时限。链接时拒绝超容、切开 Macro、无法证明安全的跨段 SR/FU 依赖和未处理的活动 WAIT；无合法切点报出队列与原因。主机首次提交时同时给有限长的目录和起始项；首版顺序、无环，不做无限硬件队列。
2. **运行期会合。** 页标签与段标记分域；按 (generation, seg_id, queue) 记录一次性退休，不能靠“最后一条已发射”或单个共享 tag 放行。最后一条指令仍可能有 MEM RegisteredR1 返回、SR 波前或 FU 尾流水。无活动指令的参与队列由目录显式声明为空，不虚等一个不会来的事件。单槽目标在退休前禁止写下一段；不相关队列不因换段请求被无条件清空。
3. **控制器状态。** RUN(k) → 等参与者退休 → 等相关旧段写提交、AXI 义务、MEM/SR/FU 尾部排空 → 取得目标槽写权限 → 用现有共享 Master 装 k+1 → 各目标末字实写 → PRIME → 前缀和依赖就绪 → START(k+1)。首版可沿用现有保守排空边界，无须先做无关事务的并发优化。仅 END 且整图末尾时限及退休条件满足才能 DONE。第一版不提前写下一段，不依赖抢占。
4. **错误与所有权。** 旧代、重复、越序标记不得二次释放；目录越界或非法目标在覆盖前拒绝。出现可归属读错则关闭新准入、排空在途、使未完成段无效，显式重装；身份/帧损坏隔离共享链路，不靠超时放槽。不把部分写完的镜像恢复成“可执行”。
5. **实现顺序。** 先用软件目录驱动同一个现有 Loader 做对照；再在 CModel 加一个有限状态控制器读取目录，复用现有分段 API/退休判断，不复制 DMA。两者对同一正式镜像逐段比 iMEM、发射序列、DDR 输出和最终 DONE；通过后才提交 RTL 接口评审。若以后需要运行期数据依赖分支，再单独评估显式 SEG_END 控制指令及条件跳转，不占用现有 QCTL 权重事件。

## 4. 两个地址空间：不要让“源地址支持”变成“目的重定位支持”

| 地址 | DEV 实际能力 | 本地产品契约与取舍 |
|---|---|---|
| DDR 源 | 向量服务适配允许非对齐字节起点。 | 公开 Loader 要求段源地址按当前物理 AXI beat 对齐；打包器对齐每段开头，记录有效字节数，padding 不生成指令。保留 4 KiB 拆 burst。底层能处理片段不能推成公开 ABI 接受任意源址。 |
| iMEM 目的 | 正常镜像没有任意目的基址字段。DEV CModel MEM 端点实验：从 word 5 连写三字被接受，但 PRIME 拒绝；历史 DEV RTL 端点实验可取 5/6/7。因此不能把这解释为 DEV 已端到端支持重定位。 | 目的为“目标队列＋单槽内从 **word 0** 开始”，word 是物理指令字，不是 DDR 字节；MEM 96-bit 字为 12 B，MXM 128-bit 字为 16 B。检查目标、容量、末字及代次。超容换段，不默默截短或覆盖旧槽。 |

**实例：**32 B beat 下，三条 MEM 字有效 36 B，源 0x1FE0 合法。即使分两次读、跨两个 4 KiB 页，也应只提交 3 个 iMEM 字，地址 0、1、2；源 0x1FE3 在当前公开 Loader 应拒绝，不用另一个目的基址来补偿。若未来要给页内多个镜像共用一个槽，须另定目的基址、界限、PRIME 取指起点及所有权，不在本轮打开。历史端点基址反例（LPU 工作区：`learn/instruction_dma_audit_20261119/README.md`）

## 5. 合作者参考与验收边界

- **已选功能，不再移植：**逻辑协议核、MEM WRITE、commit、PRIME。保持“末字接收 ≠ 实写 ≠ 可执行”。MEM 控制字 bit 1 是执行 enable；有效长段先用合法前缀启动，运行中继续取。不恢复 DEV 的整段预热门槛。见同一 160 字编译镜像的逐拍实证（LPU 工作区：`learn/dma_start_contract_20261122/README.md`）。
- **保留但非本轮改造对象：**QCTL 多播/代次/页所有权和实际退休、MEM/MXM 发射与 RegisteredR1 对齐、SXM/VXM 发射队列、数据 DMA/Peer 机制和容量选型。FIFO 引脚命名、trace 字段、首取指早晚一沿等最后统一；任何影响合法镜像或是否能 START 的行为不得以“命名对齐”覆盖。D1–D8 已决表（LPU 工作区：`lpu_src/FTLPU-VMODEL/spec_new_c7ae225/exploration/c2c/指令DMA与ICU契约合并决策表_20261121.md`）
- **建议新增验收（未执行）：**LPU16/32 同逻辑正式编译镜像，① 程序读取＋权重 LOAD＋结果 STORE 并行，分别停 AR/R/W/B，核对客户归属、无丢重；② 单段与至少三段同结果，非末段不 DONE、末段含空拍不早退；③ 旧代/重复标记、活动 SR、未退役目标、无共同切点均拒绝覆盖；④ 跨页末段、非对齐源、容量刚好／多一字、错误排空重装，核对 iMEM 逐字及目标区外未改。原生 LPU16 不为通过用例强开 common BARR。代码一致性审计不替代上述功能测试。
- **待确认的唯一新设计选择：**首版是否采用 B，即“段目录显式标记＋加载控制器自动换段”，而非增加 FU 可执行 opcode？建议采用 B，先用 MEM/MXM 单槽证明，目录格式和字段位宽待接口评审后冻结。
